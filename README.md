# PNSキャラクターリスト

パズル＆サバイバルのギルド向け、キャラクター情報登録・閲覧＋イベント運営システム。
スマートフォン基準のレスポンシブWeb。Python 3 標準ライブラリのみ（CGI）、
データベース不使用（JSONテキストファイル保存）。

- さくらのレンタルサーバー（スタンダード）のサブドメイン上で稼働中
- 稼働開始: 2026-07-11（機能凍結: 2026-07-13、以降はデザイン・文言フェーズ）

## 機能一覧

### 一般側（スマホ基準・URL は `/{サーバー4桁}/...`）

- サーバー選択（4桁番号でグループ化）
- キャラクター登録・閲覧・編集（名前／ギルド／特化兵種／Tier／部隊規模／
  ギャザー規模／避難所座標／プロフィール画像）
- 認証は「編集キー」方式（登録時に設定、署名Cookieで30日間再入力不要、
  本人によるキー変更可、忘れたら管理者がリセット。失敗5回で15分ロック、
  ロック発生は `~/pnsg-data/auth.log` に記録）
- 画像アルバム（最大10枚、削除可、画像単体URL、10枚/時間の投稿制限、
  ImageMagick/Pillow で再エンコード・EXIF除去）
- ギルド絞り込み一覧（`/{srv}/?guild=名前`）
- 避難所位置のマップ表示（1022×1023 のほぼ正方形表示、X軸2倍）
- イベント閲覧・参加登録（区分選択、認証済みキャラの自動選択）
- 予想シフト表（兵種一致優先・部隊規模均等のLPT自動振り分け、
  キャプテン=部隊+ギャザー最大、上限=キャプテンの部隊+ギャザー、溢れは補欠）
- 発表シフト（受付締切後にホストが確定・タップで任命/移動/追加。閲覧は全員可）
- 報酬分配リスト（優先順位で赤1/青5/緑20/薄黄74、出席チェック、色の固定）

### 管理側（PC基準・`/admin/`・Basic認証）

- サーバーの登録・表示名変更
- キャラクター全項目編集・画像削除・編集キー再設定・キャラクター削除
  （**削除は管理者のみ**。一般側にはない）
- イベント作成・編集・削除（開催日時・受付締切〔既定48時間前〕・参加区分・
  シフト対象の兵種・区分ごとの前後半集計・ホストパスワード）
- 発表シフトの破棄（作り直し用）

### イベントホスト（イベントごとのホストパスワード）

- 発表シフトの作成・調整（キャプテン/サブ任命、対象間の移動、未配置からの追加）
- 報酬分配リストの出席チェック・色の固定

## 開発の流れ

```
python3 devserver.py [8080]     # ローカル起動（/admin/ は認証なし）
# 修正 → ブラウザ確認 → 本番反映:
tools/deploy.sh <さくらのアカウント名> <公開ディレクトリ名>
# ~/.ssh/config のエイリアスで接続する場合は SSH_DEST=<エイリアス> を前置
# 反映後にコミットして GitHub へ:
git add -A && git commit -m "..." && git push
```

実データ（data/・backup/・www/img/）と環境設定（localconfig.py）は
.gitignore 済み。コミット時に混入しないこと。ホスティングのアカウント名や
非公開の認証情報はリポジトリに書かない方針（サイトURLとデモ用の公開キーは
上記デモ節のみ例外）。

- ローカルデータは `./data/`・`./www/img/`（消せば初期化）
- 画像縮小はローカル Pillow／本番 ImageMagick（自動判別）
- コードは Python 3.7 互換を維持（本番は 3.8.12）

## 運用

### デプロイ

`tools/deploy.sh`（rsync 差分・パーミッション正規化・localconfig 生成込み）。
本番データ（~/pnsg-data・www/pns/img）と localconfig.py は上書きされない。

### データ投入

```
tools/import_csv.py <CSV> <サーバー4桁> [共通編集キー]
```

Google スプレッドシート（Alliance/User Name/Unit Type/Tier/Troop Size/
Rally Size 列）の CSV エクスポートを一括登録。サーバー上で実行する場合は
`cd ~/www/pns && python3 ~/import_csv.py ...`。

### バックアップ（pull型・手元で実行）

```
tools/backup.sh
```

サーバーの `~/pnsg-data` と `~/www/pns/img` を手元の `backup/mirror/` に
rsync し、日付付き tar.gz を作成する（14世代より古いものは自動削除）。
cron 等の自動化はしない方針のため、**節目（イベント後・大量登録後など）に
手動で実行**すること。サーバー側には何も仕込んでいない。

### 認証情報の所在

- 管理画面 Basic 認証: `~/pnsg-data/.htpasswd`（ユーザー追加は `htpasswd`）
- 編集キー・ホストパスワード: 各 JSON に salt+SHA-256 で保存（平文なし）
- Cookie 署名鍵: `~/pnsg-data/secret.txt`（初回自動生成）

## データ保存（DBなし）

```
~/pnsg-data/
├── servers.json            サーバー一覧
├── secret.txt              Cookie署名鍵
└── {srv}/
    ├── characters/{id}.json
    └── events/{id}.json    イベント＋参加登録＋発表シフト＋報酬設定
~/www/pns/img/{srv}/{cid}/  公開画像（profile.jpg / a01〜a10.jpg / t_*.jpg）
```

書き込みは flock 排他＋一時ファイルのアトミック置換（50並列プロセスで
消失なしを検証済み）。詳細は sekkei.md の「7. 排他制御」。
